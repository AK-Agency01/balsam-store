# بَلسَم — متجر أعشاب علاجية

متجر عراقي ثابت (HTML/CSS/JS) يعمل على GitHub Pages، بدون سلة: المنتج ← العدد ← الدفع.

- `assets/config.js` — بيانات المتجر (واتساب، أرقام المحافظ، أجور التوصيل) والمنتجات.
- صور المنتجات توضع في `assets/products/` ويُكتب مسارها في حقل `image`.
- طرق الدفع: سوبر كي، زين كاش، فاست باي، فيزا/ماستر كارد، الدفع عند الاستلام.
